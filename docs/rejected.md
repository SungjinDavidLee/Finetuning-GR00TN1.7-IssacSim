# 기각된 대책

FR5 작업에서 시도했다가 데이터로 배제한 항목이다. 같은 길을 다시 걷지 않기 위해
남긴다.

---

## 1. 스케일·오프셋

| 대책 | 결과 |
|---|---|
| `PYSC=3.0` (폐루프 쓸기) | 태스크 0 만 성공. 태스크 1 에서 y 를 360 mm 과주행, 작업범위 클램프 188회 |
| `XOFF`/`YOFF`/`ZOFF` 상수 보정 | 계통 편차(−35.6 mm)를 지웠더니 오히려 −146 mm 로 악화 |
| `PZSC` 0.75 / 0.63 | task 8 `tip-rim` −0.010 → −0.045 악화. task 5 는 변화 없음 |
| `PXSC=0.88` | task 5 정렬 오차 67 mm → 85 mm 악화 |

**공통 교훈**: 폐루프에서 스케일을 줄이면 정책이 목표에 못 닿아 오차가 남는다.
개루프 비로 폐루프를 고칠 수 없다. 축별 보정은 개루프에서 유도한 값만 쓴다.

`PYSC=3.0` 은 개루프 측정 전에 폐루프로 찾은 값인데, 개루프에서 재보니 y 비가
이미 1.01 이었다. **y 편차의 원인은 스케일이 아니라 손목 카메라 미러였다.**

## 2. 그리퍼

| 대책 | 결과 |
|---|---|
| `GCLOSE=0.008` (덜 조이기) | 들기 3/3 → 1/3. 못 잡는다 |
| `GKP=30000` | 미끄러짐 0.15 → 0.34 악화 |
| `GKP=100000` | PhysX 발산. 6판이 소수점까지 동일값 |
| mimic 드라이브 해제 | 5/5 발산 |

위치 제어 드라이브에서 kp 는 잡는 힘이 아니라 위치 오차에 비례하는 복원력이다.
올리면 힘이 아니라 튕김이 커진다.

마찰은 설정에 `static 5.0 / dynamic 4.0` 으로 이미 일반값의 다섯 배다.

## 3. 물리 설정

| 대책 | 부작용 |
|---|---|
| `physics_hz` 60 → 240 | 물체가 혼자 미끄러짐 (마찰이 60 Hz 기준) |
| `stabilizationThreshold=0` | 미끄러짐 |
| `contactOffset`/`restOffset` 변경 | 파묻힘 |
| 고정물(스토브·캐비닛)에도 적용 | 서랍·손잡이가 혼자 회전 |
| 팔 토크 제한 | 중력 못 버팀. IK 실패 1164, 씬 전체 발산 |
| 그리퍼 토크 제한 | 100/30/10/3 전부 일관성 없음 |

**물리 발산은 관절 점프 제한으로 잡았다.** 물리 설정을 건드리는 것보다 IK 해를
거르는 쪽이 부작용이 없다.

## 5. 판정 기준

| 대책 | 결과 |
|---|---|
| `REFSTILL=3` (3질의 연속 정지) | 정책이 놓자마자 재파지해 그런 창이 안 생긴다 |
| `REFOPEN=-1` (개방 검사 끄기) | 모든 값이 −1 보다 커서 항상 통과. 쥔 채로도 해제로 판정 |
| 최종 위치로 채점 | 68.7 % → 30.1 %. 학습되지 않은 구간을 평가하게 된다 |

## 6. 시험 설계 오류

| # | 항목 |
|---|---|
| 1 | 발산이 안 나는 태스크(5·8)로 `MAXJ` 를 시험해 세 조건이 전부 같게 나왔다 |

| 3 | 조건당 3판으로 판정하려 했다. 우연 범위와 구분이 안 된다 |
| 4 | Franka 벤치마크가 쓰는 디렉토리 이름을 그대로 써서 20판을 덮어썼다 |
| 5 | `maxlift` 만 보고 `nclose` 를 안 봐 task 4 들기를 28판으로 과대집계했다 |

**교훈**

- 대책을 시험할 때는 **문제가 재현되는 조건**에서 한다.
- 패치는 `grep -c` 로 적용을 확인한 뒤 돌린다.
- 새 지표는 성공 판과 실패 판의 분포가 겹치는지 먼저 본다.
